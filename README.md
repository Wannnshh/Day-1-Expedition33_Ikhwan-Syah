# Prompt Engineering
Singkatnya prompt adalah instruksi singkat atau masukan yang kita berikan kepada model untuk mendapatkan hasil tertentu.
Dalam prompt AI, kita harus memasukkan detail seperti role dari AI itu sebagai siapa, tasknya apa, contextnya secara jelas membahas tentang apa, dan formatnya bagaimana.

Keuntungan melakukan prompt secara optimal antara lain adalah:
1. Meningkatkan performa AI model
2. Mengurangi bias dan merespon yang offensive
3. Meningkatkan kontrol dan predictability
4. Memberikan pengalaman yang lebih baik
