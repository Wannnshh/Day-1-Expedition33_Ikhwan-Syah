# Prompt Engineering
Singkatnya prompt adalah instruksi singkat atau masukan yang kita berikan kepada model untuk mendapatkan hasil tertentu.
Dalam prompt AI, kita harus memasukkan detail seperti role dari AI itu sebagai siapa, tasknya apa, contextnya secara jelas membahas tentang apa, dan formatnya bagaimana.

Keuntungan melakukan prompt secara optimal antara lain adalah:
1. Meningkatkan performa AI model
2. Mengurangi bias dan merespon yang offensive
3. Meningkatkan kontrol dan predictability
4. Memberikan pengalaman yang lebih baik

# Git & GitHub
Git adalah version control system yang melacak siapa, kapan, dan apa saja yang sudah dirubah dalam suatu file. Git sering digunakann di industri bidang teknologi karna fitur yang disediakan sangat berguna untuk melakukan tracking.

Dalam Git terdapat Git Workflow yang dimana terdapat 3 bagian, yaitu:
1. Working Directory/tree
2. Git Directory
3. Staging Area

-----------------------------------------------------------------------------------

# Working Directory/tree
Salinan dari satu versi proyek yang sedang kita kerjakan. File-file di dalamnya diambil dari database yang tersimpan di direktori git, kemudian ditempatkan di komputer agar dapat digunakan atau dimodifikasi

# Git Directory
Tempat Git menyimpan metadata dan object database dari sebuah proyek. Bagian ini merupakan komponen terpenting dalam git karena seluruh informasi yang dibutuhkan Git untuk mengelola proyek. Ketika kita melakukan clone repository dari komputer lain, bagian inilah yang akan disalin.

# Staging Area
File yang umumnya berada di dalam direktori Git dan berfungsi untuk menyimpan informasi mengenai perubahan apa saja yang akan dimasukkan ke dalam commit berikutnya. Dalam istilah teknis Git, staging area disebut sebagaii index.

-----------------------------------------------------------------------------------

Terdapat beberapa command git yang sering digunakan, antara lain:
1. git init (Untuk memulai repo baru)
2. git add. (Untuk memindahkan file ke staging area)
3. git comi -m 'massage' (untuk menyimpan file ke repository)
